# VIDEO DETECTION MODULE

## Introduction

The video detection module is responsible for identifying manipulated, AI-generated, and deepfake videos using computer vision, deep learning, and temporal forensic analysis techniques. The module forms an important component of the multi-modal synthetic media detection framework because video-based misinformation has become increasingly realistic and difficult to identify manually.

Modern deepfake generation techniques use neural networks, diffusion models, and generative adversarial networks to synthesize highly realistic facial movements, lip synchronization, and facial expressions. As a result, traditional media verification approaches are no longer sufficient for detecting manipulated videos.

The proposed video module performs lightweight frame-wise forensic analysis to detect suspicious visual artifacts and temporal inconsistencies commonly found in deepfake videos.

# Overview of Video Processing

A video is essentially a sequence of multiple image frames displayed rapidly over time. Most standard videos contain 24 to 30 frames per second.

The proposed framework converts uploaded videos into individual frames before performing analysis.

General workflow:

Video Input → Frame Extraction → Preprocessing → CNN Analysis → Temporal Analysis → Prediction → Explainability

# Frame Extraction

Frame extraction is the process of converting a video into individual images.

Reason:

Deep learning image models such as CNNs process images rather than complete videos.

Workflow:

1. Open video file.
2. Read frame-by-frame.
3. Store extracted frames.
4. Perform preprocessing.

Benefits:

* Simplifies video analysis.
* Reduces computational complexity.
* Enables frame-wise forensic analysis.

---

# Frame Sampling

Processing every frame of a long video is computationally expensive.

Therefore, the framework performs frame sampling.

Frame sampling means:

Selecting representative frames at regular intervals.

Advantages:

* Reduces processing time.
* Improves computational efficiency.
* Maintains important temporal information.

---

# Frame Preprocessing

After extraction, frames undergo preprocessing.

Preprocessing operations include:

* Resizing
* Normalization
* RGB conversion
* Noise reduction

---

# Image Resizing

Different videos contain frames of varying dimensions.

Examples:

* 1920×1080
* 1280×720
* 640×480

CNN models require fixed-size inputs.

Therefore, all frames are resized to:

224 × 224

This size is compatible with MobileNetV2.

Advantages:

* Consistent input dimensions
* Faster inference
* Reduced memory usage

---

# Normalization

Normalization converts pixel intensity values into a smaller range.

Original pixel range:

0 → 255

Normalized range:

0 → 1

Purpose:

* Stabilizes training
* Improves convergence
* Reduces numerical instability

---

# Color Conversion

OpenCV reads images in BGR format.

Deep learning frameworks generally expect RGB format.

Therefore:

BGR → RGB conversion is performed.

Purpose:

Ensures compatibility with pretrained CNN models.

# Convolutional Neural Networks

CNN stands for Convolutional Neural Network.

CNNs are specialized deep learning models designed for image processing.

* Convolution

# MobileNetV2

The project uses MobileNetV2 as the primary CNN backbone.

Reasons for choosing MobileNetV2:

* Lightweight architecture
* Faster inference
* Lower memory consumption
* Efficient feature extraction
* Suitable for real-time systems

MobileNetV2 is significantly smaller compared to heavy architectures such as ResNet50.

---

# Transfer Learning

The project uses transfer learning.

Transfer learning means:

Using pretrained knowledge from previously trained models.

MobileNetV2 was originally trained on ImageNet.

ImageNet contains millions of images.

The pretrained model already understands:

* Shapes
* Textures
* Edges
* Facial patterns

The model is fine-tuned for deepfake detection.

# Temporal Analysis

Temporal analysis examines relationships between consecutive frames.

Unlike image analysis, video analysis requires understanding motion consistency.

Temporal inconsistencies are strong indicators of manipulation.

---

# Temporal Consistency

Temporal consistency means:

Natural continuity between neighboring frames.

Deepfake videos may fail to maintain natural temporal transitions.

Examples:

* Sudden face distortion
* Flickering
* Lip synchronization mismatch
* Inconsistent lighting

The framework analyzes these anomalies.

---

# Optical Flow

Optical flow is a computer vision technique used to estimate motion between frames.

Purpose:

Track movement patterns between consecutive frames.

Optical flow helps identify:

* Unnatural motion
* Abnormal facial transitions
* Synthetic movement patterns

Deepfake videos often exhibit irregular motion flow.

# Loss Function

Loss measures prediction error.

High loss:

Poor prediction

Low loss:

Better prediction

Goal:

# Accuracy

Accuracy measures:

Percentage of correct predictions.

Formula:

Correct Predictions / Total Predictions

Higher accuracy indicates better performance.

---

# Validation

Validation evaluates performance on unseen data.

Purpose:

Ensure generalization.

Validation accuracy helps detect overfitting.

---

# Overfitting

Overfitting occurs when the model memorizes training data.

Symptoms:

* Very high training accuracy
* Poor real-world performance

Solutions:

* Regularization
* Dropout
* Data augmentation
* Transfer learning

---

# Confusion Matrix

Confusion matrix evaluates classification quality.

Rows:

Actual labels

Columns:

Predicted labels

Diagonal values:

Correct predictions

---

# ROC Curve

ROC stands for Receiver Operating Characteristic.

ROC evaluates classification quality.

Higher AUC values indicate stronger performance.

---

# Precision

Precision measures:

How many predicted fake videos were actually fake.

Higher precision reduces false positives.

---

# Recall

Recall measures:

How many actual fake videos were correctly detected.

Higher recall reduces false negatives.

---

# F1 Score

F1 score balances:

* Precision
* Recall

Useful for imbalanced datasets.
