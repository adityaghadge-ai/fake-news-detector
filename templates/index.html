// SYSTEM DESIGN

Framework Architecture

Explainable Multi-Modal AI Detection — Research Overview

📝

Text Module

DistilBERT CLS embeddings (768-d) fused with 9 handcrafted stylometric features into a HybridMLP. Detects AI text, fake news, and human writing with XAI explanations.

INPUT TEXT
↓ Preprocessing
↓ DistilBERT CLS (768-d)
↓ Stylometric Feats (9-d)
↓ HybridMLP Classifier
↓ PREDICTION + XAI
🖼

Image Module

Pretrained ResNet50 with transfer learning for 3-class classification. Grad-CAM heatmaps highlight suspicious regions. Forensic FFT analysis detects GAN smoothing artefacts.

INPUT IMAGE
↓ Resize 224×224
↓ ImageNet Normalise
↓ ResNet50 (pretrained)
↓ Forensic Analysis
↓ GRAD-CAM + CLASS
🎤

Audio Module

Librosa MFCC extraction (40 coefficients) + pitch, spectral contrast, ZCR, RMS energy. CNN classifier distinguishes real, AI-synthesised, and cloned voices.

INPUT AUDIO
↓ Librosa Load (22050 Hz)
↓ MFCC 40-coeff Extract
↓ Pitch + Spectral Feats
↓ AudioCNN Classifier
↓ VOICE CLASS + MFCC VIZ
🎬

Video Module

Extracts 16 evenly-spaced frames. Haar-cascade face detection. CNN frame-level analysis + temporal inconsistency metrics (flicker, drift, pixel diff) for deepfake detection.

INPUT VIDEO
↓ Frame Extract ×16
↓ Face Detection (Haar)
↓ CNN Frame Analysis
↓ Temporal Inconsistency
↓ DEEPFAKE VERDICT
